# Инструкции для Claude: репозиторий «tales-miniapp» (мини-приложение «Сказок Шахерезады»)

Это публичный фронтенд Telegram-мини-приложения. Серверная часть и вся документация проекта лежат в **приватном** репозитории `sambagirov91-a11y/Scheherazade`.

## Главное правило: документация обновляется при каждом изменении

В репозитории `Scheherazade` (в корне) лежат три документа, которые описывают **оба** репозитория:

- `ABOUT_PROJECT.md` — описание проекта, функции, тарифы, экономика;
- `FILES.md` — все файлы обоих репозиториев и за что отвечает каждый;
- `FUNCTIONS.md` — все функции: в каком файле лежат, где используются, за что отвечают.

Любое изменение в этом репозитории (новый или удалённый файл, новая, переименованная или удалённая функция, изменение поведения мини-приложения) заканчивается обновлением этих документов в репозитории `Scheherazade`. Подробности — в `CLAUDE.md` того репозитория.

Не копируйте содержимое документов сюда: этот репозиторий публичный, а документы описывают приватный бэкенд.

## Заметки о репозитории

- Сборки нет: файлы отдаются GitHub Pages как есть (https://sambagirov91-a11y.github.io/tales-miniapp/).
- Все данные приложение получает только через API сервера (`API_BASE` в `app.js`) с подписью Telegram `initData`; напрямую в базу не ходит.
- Тексты интерфейса — в словарях `miniapp-ru.js`, `miniapp-uz.js`, `miniapp-en.js` (три языка обновляются вместе).
- При изменении `style.css`, словарей или скриптов поднимайте номер версии в параметре `?v=` в `index.html`, иначе Telegram покажет закэшированный файл.
